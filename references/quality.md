# Artifact quality and delivery

Use observable checks, not invented numeric scores. For repairs, check affected requirements and regressions. For new work, inspect both the composition and the exported file.

| Check | Acceptance evidence |
| --- | --- |
| Message | Visible promise matches supplied content; no fabricated product proof. |
| Reading | Main idea survives actual viewing size and surrounding interface. |
| Copy | Names, numerals, wording, punctuation, and script shaping match the brief. |
| Subject | Required likeness, geometry, labels, and marks remain faithful. |
| Craft | Edges, anatomy, light, depth, type placement, and material behave coherently. |
| Originality | Reference arrangements are not replicated; concept serves this audience. |
| Series | Every page exists, belongs to the system, and fulfills the opening promise. |
| Export | Actual dimensions, file type, alpha, page order, and required sources verified. |
| Scope | Requested changes, output count, and known budget respected. |

A carved portrait with photographic skin needs material repair, not a new label excusing the mismatch. Failed generated lettering calls for reliable text composition. A message that disappears at small size needs hierarchy repair before texture polish. Excessive reference similarity needs a conceptual change before recoloring.

Reinspect repaired exports. Stop once acceptance conditions are satisfied. If blocked, identify the actual missing capability and deliver the best authorized artifact with honest status:
- Final: production complete and exported artifact visually inspected, with material qualifications stated.
- Unverified draft: output exists but inspection or a required technical check is unavailable.
- Production specification: no completed render; provide exact copy, dimensions, asset roles, composition/layers, and remaining dependency.

Show the visual/file first. Include concise rationale and available source/export links. Cite factual research where it affects claims. User approval and performance testing remain separate from craft review.
