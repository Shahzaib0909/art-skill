# Project records and learning

Keep useful task notes in the current project by default, when files are available. Do not create a global identity database or copy personal photographs merely because this skill was invoked. Follow existing user-approved memory settings and any instruction not to save. Cross-project persistence needs user authorization or an existing explicit setting.

For substantial or recurring work, maintain one canonical record such as design-project.md with applicable fields:
- Project, audience, destination, language, and requested deliverables.
- Locked copy/requirements, flexible choices, and labeled assumptions.
- Asset paths, roles, provenance, and known reuse restrictions.
- Selected concept, actual tool route, quantity, and known budget.
- Research URL/date/review depth, observation, hypothesis, limit, resulting decision.
- Deliverable paths, versions, inspection status, and unresolved issues.
- Feedback with date, scope, and status: proposed, delivered, approved, rejected, superseded.

Retrieve relevant records before repeating questions. Current instructions override old preferences. Drafts are not brand rules; delivery is not approval. Separate clients and projects; do not infer identity from the newest folder. Store no credentials or unnecessary personal information. Private assets and runtime records do not belong in portable skill packages.

Update the canonical record instead of accumulating conflicting copies; retain concise dated history where useful. On deletion requests, remove specified local records/copies under control and disclose any known outside copies that cannot be affected. Do not promise background capture, encryption, remote deletion, or cross-device recall the host does not provide.

An optional reference collection can grow from actually reviewed work. Each entry needs source, observation, transferable principle, unsuitable context, and limits. This skill contains no imported design corpus and must never claim to have searched one. Use targeted file search until the collection actually warrants a helper.
