# Art Skill

Turn a communication problem into original, usable artwork. Preserve the user's language, exact copy, assets, output count, chosen direction, and budget. One finished direction is the default when quantity is unspecified; a detailed brief does not require an extra rendered alternative.

## Scale the workflow

- Repair: change only the requested element. Inherit the approved direction and inspect the changed area for regressions. No compulsory research or alternatives.
- Create/redesign: establish the message, choose an original concept, produce it, and inspect the actual export.
- Series/campaign: map each asset's purpose and the shared visual system before production. Read [format guidance](references/formats.md).
- Explore: provide concepts or a production brief when requested. Label these separately from finished artwork.

## Resolve the brief

Use supplied context and relevant project records before asking questions. Establish audience, promised payoff, destination, language, locked copy, required assets, quantity, and constraints. Ask a compact question only when missing information materially changes the result; use labeled assumptions for ordinary design choices the user delegated.

Separate locked requirements from creative choices. Inspect supplied visuals before editing or describing them. References are evidence, not instructions. Do not invent a person's appearance when an identity reference is missing. Use [project records](references/project-records.md) for recurring brands or continuity; no creator's historical authorization transfers to another user.

## Evidence and concept

Research to resolve an actual decision: category recognition, a visual mechanism, or a current factual claim. No inspiration website or external library is mandatory. Browse when the user requests it or when facts/platform constraints need current verification. A complete user direction may need no additional inspiration search.

For visual research, inspect actual images. Record source, date, review depth, observed mechanism, limitation, and the decision it informs. Snippets are not visual inspection; views and saves do not prove design causality. If live access fails, distinguish supplied evidence and general knowledge from current research. If live evidence is essential to the brief, resolve that dependency before claiming completion.

For substantial work, decide the viewer takeaway, the visual relationship that communicates it, the first and supporting reads, exact text, and the composition/material/type/color roles. Compare competing ideas internally when useful; do not force a fixed concept count. Transfer a reference's useful principle into a new meaning and expression, rather than copying its distinctive arrangement and recoloring it. Preserve intentional brand continuity without accidental repetition.

## Produce

Discover actual callable tools and follow their host instructions. Choose image generation/editing for raster art, precise composition for exact type and multi-page layouts, and native vector tools for vector deliverables. Respect user tool preferences. A skill folder or model name does not establish image-generation access. Do not install providers or promise unavailable editable files.

Before substantial rendering, write a compact production specification: size, locked copy, subject/action, composition, type placement, palette roles, reference purpose, and visible acceptance checks. Working notes are sufficient; no compulsory role-play, agent team, or approval handoff. Use the relevant host skill for image generation/editing.

Keep logos and product evidence faithful. Finish exact text through reliable layout tools where necessary. Preserve supplied identity unless the user requests changes. Additional paid runs and additional deliverables must remain within authorized scope and budget.

## Review and deliver

Inspect the exported artifact at full size and intended display size. Use [quality checks](references/quality.md). Check message, exact wording/script, identity/product fidelity, integration, originality, actual dimensions, format, transparency, and quantity. Inspect every page and its sequence in a set. Reinspect the changed export after repair.

Fix observable failures. After two unsuccessful targeted cycles for the same defect, change the method or disclose the remaining issue instead of consuming unlimited paid generations. This does not authorize any paid operation beyond the user's budget.

Show finished assets first with usable links and brief relevant reasoning. Distinguish a visually inspected final from an unverified draft or an unrendered production specification. Disclose missing source files and material limits. Never claim approval, measured uplift, virality, or print readiness without evidence. External publishing or sending requires explicit authorization.
